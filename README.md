# Plataforma de Carreiras Futuras — 2035

Este projeto reúne o conteúdo desenvolvido na disciplina de Responsive Web Design junto com um backend em Node/Express.  
O objetivo é apresentar um site sobre **profissões emergentes do ano de 2035**, destacando as habilidades humanas e tecnológicas que definem o futuro do trabalho.

A proposta do tema gira em torno da relação entre:
- **Habilidades Humanas Atemporais**  
  (criatividade, empatia, comunicação, pensamento crítico e adaptabilidade)
- **Ferramentas Tecnológicas**  
  (IA, automação, robótica e computação criativa)

O site explora como a tecnologia e as competências humanas se complementam na construção da força de trabalho de 2035.

## 🚀 Tecnologias Utilizadas
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js + Express  
- **API:** JSON com lista de carreiras emergentes  
- **Integração:** Fetch API

## 📌 Estrutura
- Pasta **frontend/** para o projeto de RWD  
- Pasta **backend/** contendo o servidor Express e o arquivo JSON  
- Rota utilizada no front: `GET /api/carreiras`
